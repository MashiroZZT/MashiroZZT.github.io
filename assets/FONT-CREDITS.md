# Archive typography

Cormorant Garamond, Newsreader and IBM Plex Mono are distributed under the SIL Open Font License. Fontsource 5.3.0 WOFF2 assets load from pinned jsDelivr npm URLs. Four faces total 84,404 bytes; Newsreader italic is limited to personal running copy. Readable local fallbacks remain available if the font CDN is unreachable.

Sources: https://github.com/fontsource/font-files/tree/main/fonts/google/ and https://github.com/google/fonts

License copies:
- fonts/cormorant-garamond-LICENSE.txt
- fonts/newsreader-LICENSE.txt
- fonts/ibm-plex-mono-LICENSE.txt

Great Vibes by Robert E. Leuschke (SIL OFL) supplies the calligraphic hero motto. Source: https://github.com/google/fonts/tree/main/ofl/greatvibes ; license: https://github.com/google/fonts/blob/main/ofl/greatvibes/OFL.txt .
